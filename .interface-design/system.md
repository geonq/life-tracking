# Life OS interface system

- Calm private command center: one focal point per view, four text levels, intentional density.
- 4px spacing base; surface shifts and quiet borders are the only depth strategy.
- Adaptive light/dark semantic tokens: success, warning, danger; category accents stay restrained.
- Every metric shows owner, source, freshness, and quality. Demo fixtures are never presented as live.
- Motion communicates refresh, selection, navigation, and disclosure; all motion honors `prefers-reduced-motion`.
- Keyboard focus is visible; touch targets are compact but accessible. iPhone layout is single-column at 640px.
