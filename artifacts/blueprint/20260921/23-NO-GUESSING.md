# Dispatch gate — no architectural guessing
Planning-only. No source edits until geonq's execution go; Astra seal also required for unresolved contracts.

## Before each Luna dispatch
- Exact current SHA and untracked candidate fingerprints, not just old321a2b5 narrative.
- Exact R2-Pxx file and 14-OWNERSHIP entry; permitted ownership additions only through24.
- Existing target symbol and signature confirmed; proposed new signature distinguished from actual API.
- All referenced DTOs fully defined; no unresolved "snapshot", "session" or "result" placeholder type.
- Owner of caller/callee and dependency established; early P16 membership separated from final wiring.
- Field-level source authority, coding keys, cap, units and optional meaning explicit.
- Error mapping, cancellation point, retry ID, conflict and no-op behavior specified.
- Transaction order and old-data recovery established; no hidden second writer.
- Apple member/platform/SDK guard verified; fallback chosen; unsupported API never guessed.
- Complexity includes serialization and worst-case input; caches keyed by immutable revision.
- Required acceptance cases named and batched wave selected.
- All packet-specific CP checkpoints closed or bypassed by the explicit documented fallback.

If a contract differs from current source, worker returns exact symbol/type mismatch and minimal amendment.
The worker does not invent a signature, change a public DTO, select a new package or weaken validation.
Astra resolves it before dependent code begins; unaffected packets may continue after execution go.

## Completion report discipline
Per requirement record source status and runtime proof separately.
Count accepted IDs only after source and required evidence align; never reuse a subjective percentage.
A missing live/device environment cannot be called missing code, and existing code cannot be called verified behavior.
No blanket zero-bug/perfection guarantee; passing test counts alone do not prove visual quality/security.
No repeated full builds just to generate a status estimate.
