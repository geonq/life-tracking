- Authority: explicit user requirements → this `tasks/design.md` → compatible historical references. - [Skills UI Clean](https://www.skillsui.app/skills/clean): adopt deliberate spacing, consistent controls, focused actions, complete hover states. ## 6. Motion and navigation ownership
- Curve for custom ease-out: cubic Bézier (0.16,1,0.3,1). Hover fill/border 120ms; press immediate fill, release 140ms; no text/button scaling, card lift, icon bounce or global spring. Keyboard focus is independent and never changes geometry. Exit/release outside cancels the action.
- Top-level desktop route: 120ms crossfade, fixed shell; no zoom, card flight, or full-page spring. Home→Usage/Clipper detail: stable header, incoming opacity 0→1 and x=8→0 over 180ms; outgoing 120ms fade. Back mirrors direction, never replays all card/ring entrances.
- iPhone detail navigation uses the native interactive push/pop; no second custom transform layered over it. Sheets use native presentation and interactive dismissal; dirty forms require Keep editing/Discard confirmation.
- Reversal: retarget from current presentation values and velocity, not initial keyframes. Route identity owns task/animation cancellation; latest navigation wins. Test A→B→A at 50/100/150ms; one visible interactive destination, no flash, duplicate focus, or delayed navigation callback.
- Retain per-route scroll, filters, chart selection where dataset identity permits, and drafts across back navigation. Refresh does not remount the route, reset scroll, or replay reveal effects.
- Selectors/reorder settle: spring response 0.24s, damping 0.90; calendar pager 0.28s/0.92. Direct drag/scrub/pinch tracks input without implicit animation; no spring lag while touching.
- Charts/rings render final geometry on ordinary entry; no draw/sweep replay on return, refresh or provider change. Data revisions may crossfade in 100ms, never interpolate fabricated financial observations. Scrub follows directly; 80ms tooltip opacity only. One selection/commit haptic on supported phone hardware, none for passive scrolling.
- Reduced Motion: no translation/scale/reveal, immediate state or ≤100ms opacity; preserve direct user manipulation. A mid-animation setting change cancels old completion work and settles the latest intent. No perpetual idle animation; pause offscreen work; profile one build/device at a time.

## 7. Truthful state model, shared by all modules

| State | Presentation and behavior |
|---|---|
| Initial loading | Compact progress/status region, no giant chart skeleton; after 5s show “Still loading” with supported Cancel/Retry; no fake values or premature connection diagnosis |
| Refreshing | Retain last valid content and geometry, one toolbar spinner; coalesce refreshes; show original timestamp until success |
| Live / observed zero | Real value and actual source time; zero is `0`, not a dash; “Live” only when connector and freshness contract permit |
| Partial / stale | Retain only permitted last-known values with “Updated …”/“Some sources unavailable”; explain affected source in details |
| Never connected | One compact 72–104-high setup region at default type; collapse absent chart/category scaffolding; one Connect action |
| Filtered empty | Preserve range/filter controls, explain “No transactions in this range”, offer Clear filters; never trap selection |
| Permission / expired access | “Reconnect [source]” or supported authorization action; never infer Health permission denial from an indeterminate read or missing samples; no endless Retry loop |
| Transport / validation error | Useful plain-language error, bounded retry; no stack trace, API command, raw response, key, account number, or document text |
| Saving / failed save | Prevent duplicate submission; success only after persistence; failed save retains draft and focus, with inline retry |
| Redacted / configured but unread | Redaction removes protected values, plots, tooltips and accessible strings immediately; configured-but-unread says “No account data received yet”, not disconnected or live |
- Provenance details live behind a source/status disclosure; replace “reviewed source”, “durable storage”, “in-memory”, “quality unavailable” developer copy with user outcomes. Do not hide uncertainty needed to interpret a value.
- Demo data is an explicit visual-test mode with a compact persistent “Demo” badge; never production fallback. Screenshot fixture tests must be labeled; live acceptance uses actual connected data with private captures handled locally.

## 9. Calendar: scrolling, magnification, and editing
- Preserve mobile three-day strip: today/tomorrow/day-after; one-day increments per swipe. One fixed 44pt time gutter, pinned date header, coordinated all-day/timed horizontal translation. Mac gutter 52; default week view with equal day columns.
- Timeline is one vertical scroll owner, 00:00–24:00 inclusive; default hour height 64, bounds 40–120 from current CalendarInteractionLayout. Bottom clearance = residual measured occlusion not already removed by safe-area layout +24; unique 24:00 label and 23:45 event reachable with ≤24 spare tail. No viewport-height trailing spacer or double-counted bottom bar.
- All-day lane preserves n+1 cells. Keep it separate from timed vertical scroll; large all-day lists get bounded dedicated disclosure rather than consuming the entire timeline viewport.
- Now indicator: one time label in gutter, one dot/line restricted to today's visible column; none if today absent. Avoid collision by hiding the nearby static hour label within 12pt. Never repeat current time across all days.
- Gesture arbitration: after 8pt movement, lock axis when |x| ≥1.3|y| for paging or |y| ≥1.3|x| for scrolling; ambiguous diagonal stays undecided until 16pt, then defaults to scroll. Native leading-edge Back wins. Ordinary swipes over event bodies/resize affordances must still scroll until deliberate edit activation.
- Tap opens; double-tap empty time creates; long press 350ms then drag creates/moves, explicit edge-handle press then drag resizes. Snap commits to 15 minutes, show exact draft time while moving; cancel discards preview. During edit, disable day paging and use edge auto-scroll; preserve recurrence scope confirmation and DST rules.
- Mac pinch over timeline changes hour density: capture h0, offset0, focal y; t=(offset0+y)/h0; h=clamp(h0×magnification,40,120); offset=clamp(t×h-y,0,contentHeight-viewportHeight). Keep focal time within 2pt except at scroll bounds.
- Pinch owns magnification only; two-finger scroll owns scrolling, never changes route/month. Stop scroll momentum at pinch begin. Ignore pinch during active event mutation; cancelled pinch restores initial scale/focal offset. Commit density per scene only at gesture end.
- Header-region Mac pinch: outward factor ≥1.12 expands month, inward ≤0.88 collapses; owner fixed at gesture begin even across region boundaries. Track month reveal directly, settle 240ms ease-out; cancel restores start state/scroll anchor. Timeline pinch changes density only. Date-chevron/keyboard action is the equivalent fallback; Density menu Compact 40/Default 64/Spacious 120, Reset 64. Remove dotted slider/oversized thumb. Phone header tap expands; do not steal timeline pan for expansion.
- At 40pt/hour short events may use a compact visual marker; selection opens full detail with ≥44pt phone hit affordance without invisible overlays blocking timeline scroll. Keyboard arrows/escape and undo preserve current editing behavior.
